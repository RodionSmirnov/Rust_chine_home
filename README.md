# Rust Loot Finder

Приложение на Python с русским интерфейсом и чёрно-белым оформлением.
В репозиторий включены **1307 предметов**, **1297 картинок** и таблицы
для **42 из 45 выбранных контейнеров**. Работает без интернета.

## Запуск

Нужен Python 3.10+. Сторонние библиотеки не нужны.

```sh
python3 app.py
```

Открой `http://127.0.0.1:8000` на том же компьютере. Windows: `py app.py`.
Другой порт: `python3 app.py --port 8080`. Завершение: Ctrl+C.

Выбери контейнер, чтобы увидеть все предметы из его таблицы, количество,
состояние, категорию и вероятность выпадения. Есть поиск по русскому или
английскому названию и shortname, фильтр категорий и сортировка.
«Все предметы · каталог» показывает полный список базы, включая служебные
предметы и предметы, которые не выпадают из контейнеров. В этом режиме
вероятность не назначается: она зависит от выбранного контейнера.
638 названий взяты из русской базы
[Khan8615/RustItemTranslations](https://github.com/Khan8615/RustItemTranslations/blob/5e69bc9a7cb7b2faa35d4350993247c5828c76ba/ru.json)
по точному совпадению shortname. Описания и английские значения из неё не импортировались.
Для остальных предметов сохранены прежние русские или английские названия.
Снимок базы переводов датирован 30 ноября 2021: новые предметы в ней отсутствуют.
Переводы хранятся в `localization/items.ru.json`, ссылка на источник и commit —
в `localization/provenance.json`. Обновление игровых таблиц их не перезаписывает.

В списке контейнеров оставлены ровно 45 пунктов с пользовательского скриншота,
в том же порядке. Точный список с привязкой к игровым prefab — `config/containers.json`.
Остальные контейнеры удалены и из списка, и из локальных таблиц выпадения;
обновление базы также применяет этот список.

Для **Foodbox 2**, **Scientist PT Boat Drybox** и **Scientist RHIB Drybox**
в текущем экспорте нет подтверждённых таблиц. Эти три пункта присутствуют
с явным сообщением об отсутствии данных, без подстановки вероятностей от
других ящиков. Полный каталог предметов сохранён отдельно от списка контейнеров.

## Версия и происхождение

Источник: [bobosneefdev/rust-items-json](https://github.com/bobosneefdev/rust-items-json),
экспорт файлов игры, commit `1204329518584db8e7f242e0f5671edeebf9d18e`.
Включена сборка **25824447**, данные обновлены источником **10 октября 2026**,
проверены им **12 октября 2026**. Это последняя доступная версия найденного
источника при загрузке; соответствие последнему патчу на 19 октября не подтверждено.
Приложение всегда показывает сборку и дату базы, а не заявляет, что она актуальна сегодня.

Шансы взяты из `loot-probabilities.json`, не введены вручную.
Процент означает вероятность хотя бы одного экземпляра при заполнении
контейнера. Расчёт относится к vanilla-таблицам до ограничений вместимости
инвентаря и модификаторов игровых режимов. Проценты не складываются.
Диапазон количества включает 0, когда предмет может не выпасть.
Список содержит только выбранные контейнеры, включая корабль-призрак и
подводные/вагонные варианты. Неиспользуемые служебные контейнеры исключены.

Картинки включены локально. У 10 служебных/специальных предметов источник
не предоставил иконку; для них показывается обозначенная заглушка.
Игровые данные и изображения принадлежат Facepunch Studios. Программа
не связана с Facepunch. Лицензия кода источника сохранена в `data/SOURCE-LICENSE.txt`;
происхождение снимка — в `data/provenance.json`.

## Обновить базу

Останови приложение, затем выполни (нужны Git и доступ к GitHub):

```sh
python3 update_data.py
python3 app.py
```

Скрипт скачивает последнюю доступную версию источника, берёт JSON и картинки
из одного commit, проверяет связи предметов и таблиц, затем заменяет локальную
базу, сохраняя только контейнеры из `config/containers.json`. При сбое скачивания старая база сохраняется. Скрипт не гарантирует, что
автор источника уже обработал самый свежий патч Rust. Проверяй дату и сборку.
Для уже скачанного чистого checkout источника:
`python3 update_data.py --source /path/to/rust-items-json`.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Проверяются полнота каталога, сохранность всех вероятностей источника,
доступность локальных картинок, русские названия, точный список контейнеров,
сохранение фильтра при обновлении, HTTP API и обработка ошибочных запросов.
