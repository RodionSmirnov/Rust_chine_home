# Rust Loot Finder

Приложение на Python с русским веб-интерфейсом: выбор контейнера Rust,
поиск предметов по названию из источника, сортировка по вероятности,
картинки предметов и локальный кэш таблиц. Названия предметов остаются на языке источника.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.

```sh
cd Rust_chine_home
python3 app.py
```

Открой `http://127.0.0.1:8000` в браузере на том же компьютере.
Windows: можно использовать `py app.py`. Другой порт: `python3 app.py --port 8080`.
Завершение: Ctrl+C. Сервер слушает только локальный интерфейс.

## Данные и изображения

Источник таблиц и изображений — https://wiki.rustclash.com.
При выборе ящика приложение загружает HTML-таблицу с колоночными заголовками
Item / Amount / Chance. Картинки берутся из этой таблицы, не генерируются.
Данные сохраняются в `.cache/`, кнопка «Обновить» запрашивает свежую таблицу.
Дата в интерфейсе — время загрузки, а не дата обновления игры.
Кэш не распространяется вместе с программой. При неудачном обновлении
сохранённые данные отображаются с предупреждением.

Если сайт заблокирован, сохрани страницу нужного контейнера в браузере
как HTML и используй «Импортировать сохранённую таблицу». Нужно сохранить
саму таблицу, а не страницу проверки браузера. Соответствие HTML выбранному
ящику проверяет пользователь. Импортированный HTML не исполняется.
Изображения требуют доступа к сайту даже при использовании кэша.
Если таблица изменила формат, приложение сообщает об ошибке вместо выдуманных процентов.

Проценты разных предметов не следует складывать: контейнер может содержать
несколько предметов. Знаки `<` и `~` сохраняются из источника.
Лут зависит от версии игры и настроек сервера. Это неофициальное приложение;
права на игру и изображения принадлежат их владельцам.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Тестовые проценты вымышлены и используются только для проверки парсера.
При разработке в облачной среде сайты с таблицами возвращали HTTP 403
от сетевого прокси: актуальные игровые таблицы и картинки не были проверены.
Для использования нужен доступ к источнику или импорт реальной таблицы.
